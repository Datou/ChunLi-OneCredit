# 网页存档兼容性

训练存档采用 Gym Retro 版 Genesis Plus GX 1.7.5，网页 core 使用 1.7.6。两个版本的状态都使用 1,036,288 字节缓冲区，工作内存、显存和 VDP 寄存器同偏移。控制字段和 CPU 上下文的后续布局不同。

网页存档生成保留旧存档 `[0, 140613)`，将文件头写成 1.7.6，并使用当前 core 在开场采集的模板补齐剩余运行控制状态。偏移 `[140581, 140613)` 的 VDP 寄存器和显存一并保留。中国街开场使用这些寄存器配置逐行横向滚动。接着用网页同款 core 校验开场的输入锁和双方血量。

网页生成器用于恢复可运行的关卡开局。训练和评测需要 Gym Retro 的原生状态。两种文件的生成命令见[存档制作](savestates.md)。
